# TestHarbor brand assets

`testharbor-app-icon.svg` is the source of truth for the application icon. `testharbor-app-icon.png` is the 1024 px raster input used by the Tauri icon generator.

Regenerate platform assets from the repository root after changing the SVG and reviewing it at small sizes:

```bash
cd apps/desktop
npm run tauri -- icon ../../design/brand/testharbor-app-icon.png
```

The supported desktop release is currently macOS. Mobile icon output generated by the Tauri CLI remains ignored until those platforms are intentionally supported.
