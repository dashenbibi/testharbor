# Provisional TestHarbor brand concept

This directory contains the approved source mark and review preview. The generated image explorations remain local and are excluded from public exports.

- `testharbor-mark.svg` is the cleaned, deterministic vector concept.
- `testharbor-mark-light-preview.png` is the review preview on a light background.

## Rationale

The charcoal open frame represents an isolated run boundary rather than a shield or security guarantee. The moss path enters that boundary and resolves into a check-like turn, representing controlled execution and evidence-backed completion.

Colors match the existing desktop interface:

- Moss: `#A9C77C`
- Charcoal: `#151611`

The application icon set is generated from the approved vector source. Keep the SVG as the source of truth and regenerate raster/platform assets rather than editing them independently.
